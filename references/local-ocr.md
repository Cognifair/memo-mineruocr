# 本地非 MinerU OCR

此路线的重点是离线、非 MinerU；不是把 MinerU 下载到本地，也不是偷偷改用别的云服务。

- 检查已安装的 OCR 引擎和语言包，例如 PaddleOCR、Tesseract，或当前环境真正支持的本地视觉识别工具；不把“能打开图片”当成可批量离线 OCR。
- 原生文字 PDF 优先提取现有文本，扫描页再调用已选本地 OCR。保留页序与页码定位，复杂表格、公式和双栏材料说明引擎的局限，不承诺自动重建。
- 需要安装引擎、下载模型或更换路线时先说明内容、来源、资源成本，并遵循当前安装授权。无可用引擎可先完成只读检查和拆分方案，不声称 OCR 已完成。
- 大 PDF 也可使用本技能 `prepare` 做页对象拆分。云端 ZIP 合并器要求与清单一致的分片 ZIP；本地工具输出不是该结构时，用实际格式做独立合并和同等的覆盖/素材检查，不伪造云端成功状态。
- 非 PDF 的 Office 材料先按已有文档技能进行原生读取；必须转 PDF 时保留原件并说明页码可能变化。不为绕过本地路线把文件发往在线转换站。
- 最终同样交付 Markdown 与实际生成的素材；注明采用的本地引擎和已知识别限制。只提取文本而未保留图表时必须明说。
