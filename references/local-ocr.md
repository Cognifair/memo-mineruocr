# 本地 MinerU OCR

这条路线的重点是：**用本机安装的 MinerU 引擎识别，不上传、不使用云端 Token。** 不是 PaddleOCR/Tesseract 路线，也不是偷偷改用别的云服务。

## 先检查引擎

```text
mineru --help
```

或使用你实际安装的本地 MinerU 服务/CLI。不同版本的 MinerU 命令可能不同，以本机 `--help` 和官方文档为准。

- 没有安装时先说明，询问是否安装；不要自动下载模型或安装大型依赖；
- 安装源、模型大小、磁盘/显存占用和许可证要在安装前说明；
- 不要因为本地 OCR 失败就静默切换云端；换路线要用户同意。

## 处理流程

1. 原生文字 PDF 优先提取现有文本；扫描页再调用本地 MinerU。
2. 大 PDF 可用本技能 `prepare` 做页对象拆分；本地引擎输出按实际格式独立合并。
3. 保留页序、页码定位和实际生成的素材；不要伪造云端任务清单。
4. 复杂表格、公式、双栏、手写材料要说明本地引擎的局限；不承诺自动重建。

## 输出

- 交付 Markdown 与实际素材；
- 注明使用的本地 MinerU 版本/命令和已知识别限制；
- 只提取文本而未保留图表时必须明说；
- 离线通过不代表真实文档的 OCR 准确率已验证。

## 禁止

- 把本地路线说成云端精准解析；
- 未安装就假装已识别；
- 静默改用 PaddleOCR/Tesseract 或在线转换站；
- 为了绕过本地限制把文件上传到未授权服务。
